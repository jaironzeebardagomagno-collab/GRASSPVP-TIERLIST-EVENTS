GRASS Tier List V6

Upload only these 3 files to your GitHub repository:
- index.html
- script.js
- style.css

V6 changes:
- Removed the Players page/tab.
- Kit Tier List is the main page.
- Each kit has LT5, HT5, LT4, HT4, LT3, HT3, LT2, HT2, LT1, HT1 sections.
- The central icon is ALWAYS the kit icon (for example, DiaSMP stays the DiaSMP icon at every tier).
- Tier aura color changes based on LT5/HT5/etc.
- Added editable Tier Aura Colors in Settings.
- Keeps editable #1, #2, #3, #4-10, #11-50, #51-100 leaderboard aura settings.
- No assets folder is required; icons are inline SVG.

If GitHub Pages still shows the old design, hard refresh the site or clear the browser's site data because the previous version used localStorage.
